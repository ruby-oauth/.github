Ruby OAuth maintains OAuth protocol libraries for Ruby and the small supporting gems that keep those libraries easier to test, document, and operate.

For support, security-adjacent coordination, and contributor questions, use [Ruby Users Forum][ruby-forum] or [Discord][discord].

## Community And Support

Use [Ruby Users Forum][ruby-forum] for longer support threads and protocol
coordination. Discord is available for live coordination.

Fun fact: the ruby-oauth project was the original OAuth project for Ruby. It is now more than 18 years old and began at Twitter when Twitter still ran on Ruby.
